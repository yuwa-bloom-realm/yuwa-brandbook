# あなたの物語に、続きを。｜ゆわ Bloom Realm ブランドブック

体験会に来てくれた方に渡す、めくれるブランドブック（Webアプリ）だよ。

## できること
- 表紙〜個別相談まで、ちゃぴぴのイラスト全13ページをめくって読める
- ハープのBGMがそっと流れる（右上の ♪ でオン／オフ）
- **11ページ「今日の物語を振り返って」は、その場で文字を書き込める**
- 書いたワークは「このページを画像で保存」でイラストごと1枚絵になる（お守り／Threads投稿用）

## 操作
- 次へ／戻る：画面の左右をタップ、横スワイプ、または左右の矢印
- ワークページだけは、枠をタップして入力 → めくるときは矢印を使ってね

## GitHub Pagesで公開する手順（iPhoneから）
1. このフォルダの中身を丸ごとリポジトリにアップロード（index.html が一番上に来るように）
2. リポジトリの Settings → Pages → Branch を `main` / `/root` に設定して保存
3. 数分待つと `https://（ユーザー名）.github.io/（リポジトリ名）/` で公開される

## 中身
- index.html … 本体
- 01_cover.jpg 〜 13.jpg … 全ページ画像
- bgm.m4a … ハープBGM
- html2canvas.min.js … 画像保存機能（同梱・外部通信なし）
- manifest.json / icon-*.png … ホーム画面追加（アプリ化）用

## 差し替えたいとき
- ページ画像を差し替える → 同じファイル名で上書き
- BGMを変える → bgm.m4a を差し替え
- 入力欄の位置を微調整 → index.html の `FIELDS` の座標（0〜1の相対値）をいじる
